设计说明与演示边界

访问 key 只用于服务授权；每个库的加密密码由用户在插件里设置。所有密码、授权、安全保存、同步状态都是交互模拟，刷新页面重置全部数据。

后台与插件共享本页内存中的演示状态，可查看刷新 key、停用、删除对已连接插件的影响。复制功能只处理明确标记为 demo 的访问 key。

管理端刷新访问 key 只改变访问权限，不改变库主密钥或加密密码。停用会阻止所有设备；删除会移除用户和远端库，但不删除设备上已有的本地文件。

库名默认取本地文件夹名，绑定依据稳定的库 ID。接入已有库需明确选择；不会因同名自动合并。首次创建时先设置加密密码，再上传。

加密密码只在本机处理，后台无法恢复。两种凭据分别模拟安全保存，保存后输入框清空并显示固定圆点占位；此 HTML 没有执行加密或系统安全存储。
