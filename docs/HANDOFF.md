## 当前推荐方案，仍需验证

- 插件：TypeScript + Obsidian API。
- 本地状态：IndexedDB + Dexie；大字节另存加密暂存。
- 服务端：Go + PostgreSQL，密文字节放不可变对象存储；个人部署默认本地持久化磁盘，S3 是扩展后端。
- 独立同步协议：稳定随机文件身份、位置与内容修订分离；因果分支、幂等操作、按库提交序列、事务化路径与对象引用。
- 加密候选：随机库主密钥、Argon2id 封装、独立用途子密钥、XChaCha20-Poly1305。
- 小文件整块；大文件 FastCDC 候选。参数、历史 90 天建议和移动端资源约束都未定为发布合同。
- 备选方案比较已在 HTML 中涵盖 PouchDB/CouchDB、SQLite、RxDB、WebDAV/S3、CRDT、Git / 系统级同步。

完整语义以 `docs/DECISIONS.md` 和 HTML 正文为准。用户要求“最优”应转化为可验证的可靠性、恢复、隐私和资源目标，不把当前推荐当作不可更改的选型。
