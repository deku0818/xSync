# 连接 Obsidian

## 1. 安装 xSync

在 Obsidian 的“设置 → 第三方插件 → 浏览”中搜索 **xSync**，安装并启用。

也可以从 [GitHub Releases](https://github.com/deku0818/xSync/releases) 下载 `main.js`、`manifest.json`、`styles.css`，放入笔记库的 `.obsidian/plugins/xsync/`，再启用插件。

## 2. 填写连接信息

向管理员取得自己的服务地址和访问 key，打开 xSync 设置，填写：

- **客户端名称**：用于区分设备，同一同步库内不能重复。
- **服务器地址**：手机和远程设备填写 HTTPS 地址，例如 `https://sync.example.com`；本机测试可用 `http://127.0.0.1:8873`。
- **访问 key**：管理员在后台创建用户时提供的 key。

点击“保存并测试”。管理端登录密码不填在这里。

## 3. 创建或加入同步库

- **第一台设备**：选择“创建同步库”，确认库名，设置并备份库加密密码，点击“创建并开始同步”。库名默认使用当前本地库的文件夹名称。
- **其他设备**：使用相同服务地址和访问 key，选择已有同步库，输入同一个库加密密码。

在一端新建笔记，确认另一端出现，再反向修改一次。两端均显示“已同步”即完成。

访问 key 用于连接服务器；库加密密码在设备上用于解密笔记，不会上传到服务端。服务器无法解密知识库内容，管理员也无法找回库加密密码，请单独保存。

## 日常使用

暂停后可以继续编辑，恢复时自动补齐。遇到冲突，点击同步状态查看差异并选择保留内容。

管理员刷新 key 后，在各设备填写新 key 即可，原库加密密码不变。
