# 0.0.5 设置界面与连接测试

日期：2026-10-14，Asia/Shanghai。只更新生成的 A/B 测试库插件 JS、CSS、manifest；未操作真实库或部署服务。

## 界面

服务器连接卡片包含地址和密钥；“保存并测试”与密钥输入框同行。底部显示服务器连接、设备授权、密钥校验、安全保存四项反馈；错误有具体原因。暂停/恢复放在独立同步状态区域，开发范围折叠显示。样式使用 Obsidian 主题变量并限制在插件容器内；CSS 随构建、测试库 provisioning 一起复制。

普通本地演示 `design/connection-settings.html` 可模拟首次配置、成功、密钥错误与暂停；不连接服务器。内置浏览器阻止 file URL，本轮没有绕过该限制；实际视觉检查直接在 Obsidian 设置窗口完成。未声称已检查手机和所有主题下的排版。

## 测试语义

“保存并测试”先执行带设备授权的真实 `/handshake`，核对库、设备、协议、epoch/已见进度，再用输入密钥解密密钥包。密码框留空时复用 OS 保护的会话材料，验证材料完整性及同一密钥包锚点。校验成功后才保护新记录并切换设置引用；失败保留原配置。测试阶段不提交笔记、创建对象或修改同步队列；保存成功后按已有同步开关继续工作，暂停状态不会被测试打开。

四项反馈来自实际步骤；没有用延时动画充当连通性结果。设备授权失败与加密密钥失败分开；这里测试的是同步握手和解密能力，不声称验证了所有对象读写、磁盘耐久性和实时通道的端到端可用性。
