# 0.0.6 桌面实现与验收

日期：2026-10-15，Asia/Shanghai。按照已审阅的 `design/connection-settings.html` 与 `design/sync-conflicts.html` 实现。仅使用本项目生成的 A/B 假库、专属 Docker PostgreSQL 和本机 Go 服务；未发布、未部署到外部、未操作真实笔记库。

## 已实现

- 连接页与同步/冲突页移植到插件，静态 HTML 模板和样式限定在插件容器内，不包含演示脚本。地址、客户端名、留空复用密钥及保存并测试接入真实服务。
- 名称在同一 vault 内唯一：服务端 trim、NFKC 和 Unicode case-fold，通过 PostgreSQL 唯一索引原子判重；重启不会把新名称改回启动配置。用户改名不改变 device ID。
- 本机规则独立持久化：1–100 MB（十进制，100 MB = 100,000,000 字节）、文件夹、后缀、正则。文件夹以完整路径边界匹配；后缀大小写无关；RE2 正则可命中文件或目录并对子内容继承。正则不支持回溯引用和前后查找，UI 明确提示。
- 每个客户端向服务器上报加密配置快照，绑定 vault/device/revision；快照更新有 CAS，丢回执以同一密文/修订重试。其他客户端解密后只读查看最近上报值，不自动套用规则；不把上报时间当成在线证明。名称是用于唯一约束的服务器元数据，规则快照为 E2EE。
- 名称/快照被服务器接受和本机凭据保存是不同边界，不构造跨系统事务。本机保存失败时旧本机连接保留，服务器可能已接受名称更新；重试核对最新修订。审阅中的“此设备”依据稳定 device ID，不按可修改名称判断。手动解锁还验证已保留修订的密钥，防止旧自动解锁材料不可用时混用新主密钥。
- `.obsidian` 共享主题、插件程序和可共享配置。实际目录从 `Vault.configDir` 获取，使用 Adapter，线上逻辑路径统一为 `.obsidian`；普通文件仍用 Vault API。隐藏配置使用元数据轮询触发，部分主题/插件设置需要重载 Obsidian 才生效。
- 固定排除本插件自身、解锁记录、身份、队列/暂存、开发标记、workspace 布局、隐藏缓存和明确的凭据文件。JSON 中识别的 API key、token、password、device ID 等字段留在本机，应用共享字段时保留接收端自己的值；含凭据的数组整体留在本机，避免按数组下标误配凭据。同步插件自己的启用状态不进入共享启用列表。
- 真实排除文件树读取索引/metadata，不读取正文；整目录标注、按需展开、每批 50 项。固定私有目录不为统计而递归扫描，未知文件数不会虚报；文件变化会更新结果，未变的索引不反复重建节点。箭头为固定尺寸居中 SVG。
- 排除策略同时用于捕获、上传队列、接收应用与应用日志。被排除的已跟踪记录保留，排队任务保留，不因扫描列表少了文件就产生删除。恢复纳入时重新核对因果分支；无关文件继续。
- 文件内容按最多 4 MiB 明文块加密传输，每对象仍低于服务器 16 MiB 密文上限。manifest/本机加密 stage 支持硬边界 100 MB；接收时按已认证 manifest 长度分配并逐块校验，不把分块传输称为源文件流式读取。
- 冲突按真实设备名、准确修订、完整短文本并排展示。无预选；保留双方必须选原路径归属并预览另一份路径；手动合并以所有已审阅头创建 manual resolution。点击确认时冻结快照、路径和正文，提交时同时检查内容头与位置修订。新版本清除旧选择并保留草稿；草稿只以设备密文存放在本机 IndexedDB。
- 二进制或超出 64 KiB 的文本不做截断后选择，保持待处理；多于两份的完整 UI 审阅仍待支持。删除/编辑冲突可明确采用删除或文件版本，不把删除当成空正文；删除版本不提供保留两份文件的误导选项。

## 初始化路径竞争与恢复

真实 A 已有旧检查点，B 先上传共享配置；A 捕获相同路径的新 file ID 时出现 PATH_OCCUPIED，旧应用任务又因本机路径唯一索引卡住。修复顺序：接收元数据先于捕获；只有服务端明确拒绝 create、且远端已有同路径不同身份、没有复杂移动/跨文件组时，才归档原 outbox、本机身份和应用日志，再重新核对当前实际字节。精确相同字节可接入已知修订；不同内容以无父的独立根保留为正常冲突，不猜祖先。原密文/操作记录保存在 `rejectedOutbox` 与 `reconciliations`，不清空库。

每个恢复任务隔离失败；不能因为一个旧文件 journal 阻止其他文件。全局 lease/锁定失败仍停止执行。归档后中断有故障注入测试，重试恢复双方独立版本；未知状态、复杂位置竞争保留任务待核对。

## 仍需验证/限制

- 仍限制生成的开发库与预置设备令牌，正式配对、撤销、轮换和生产审查未完成。
- 源文件仍整文件读取，100 MB 桌面传输不证明手机峰值内存可接受。iPhone/Android、物理双机、Windows/Linux安全存储、OS 重启及全面强杀/断电仍待验收。
- 第三方插件凭据只能根据明确路径与已识别字段隔离，不能普遍推断任意自定义字段的含义；未知私密字段需排除相应插件目录或增加适配。含本机字段的配置文件遇远端删除会保留该文件和恢复任务，防止删掉凭据。
- 空目录、批量目录移动、完整多版本/附件处理、复杂位置恢复、历史/GC和联合备份仍待完成。归档是恢复保护，不等于完整历史/恢复浏览器。
- 端到端加密使服务器不能直接证明明文文件长度；客户端执行 100 MB 明文硬边界，服务端执行密文对象/请求边界。
