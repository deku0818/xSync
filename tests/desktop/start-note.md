# ObsidianSync 自动同步测试库

这是独立生成的测试库，仅放假笔记。

1. 开发服务保持运行：项目根执行 `npm run desktop:start`，PostgreSQL 只使用 Docker。
2. 打开插件设置，填写本机唯一客户端名称、服务器地址 `http://127.0.0.1:8873`，同步密钥填 `<TEST_PASSPHRASE>`，点击“保存并测试”。这是公开测试密钥，不能用于真实库。
3. 保存后自动连接和同步；后续打开测试库无需重复输入密钥。
4. 编辑“同步试验.md”即可，Obsidian 保存或自动保存后会上传，另一库通过实时通知自动接收。
5. 重叠修改只暂停相关文件；比较页显示准确设备名称和差异，让你选择保留双方、某一方或暂不处理。审阅期间有新修改会刷新比较并清除旧选择。
6. 日常只有“暂停同步 / 恢复同步”：暂停保留配置和本地笔记，重开后仍暂停；恢复后自动补齐，无需重输密钥。

本机解锁材料由设备安全存储保护，不把库口令或明文加密密钥写进插件设置；服务器只有加密密钥包和密文。设备令牌仍属于开发预置配置，不复制到真实库。

当前开发范围：普通文件与可共享配置，单文件上限可配置 1–100 MB；支持每设备文件夹/后缀/RE2 正则、排除树和客户端快照。完整预览选择/合并限 64 KiB 短文本；空目录、完整历史/备份和手机验收仍待完成。实际安全存储与自动同步已验证当前 Mac，Windows/Linux 尚待真机验证。
